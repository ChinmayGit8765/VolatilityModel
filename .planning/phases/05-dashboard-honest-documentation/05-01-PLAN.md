forecast_vs_realized parquet (from src/volforecast/monitoring/labeller.py):
  Path: data/monitoring/forecast_vs_realized.parquet
  FVR_SCHEMA columns:
    as_of_date (tz-aware UTC Timestamp), asset (str slug e.g. "BTC-USD"),
    horizon (int, =1), model_version (str), model_alias (str —
    "champion" or "garch_baseline"), forecast_var (float decimal variance),
    realized_var (float decimal variance).
  Per-asset time series: filter model_alias=="champion" for the forecast line,
    model_alias=="garch_baseline" for the GARCH baseline line, and realized_var
    is the realized series (same column in both alias rows).

Drift reports (from src/volforecast/monitoring/drift.py):
  Written by run_distribution_drift to data/monitoring/{date_str}_drift.json
    and {date_str}_drift.html, where date_str is e.g. "2026-06-12".
  The JSON is Evidently 0.7 result.dict() — a nested dict. The dataset-level
    drift flag appears as a "dataset_drift" boolean somewhere in the nested
    structure (per tests/unit/test_drift.py). Parse defensively: locate the
    boolean and a count of drifted columns by traversing the dict; never assume
    a fixed top-level key path. Reference snapshots live under
    data/monitoring/reference/ — do NOT read those for the drift panel.

prediction log parquet (from src/volforecast/serving/prediction_log.py):
  Path: data/predictions/predictions.parquet
  PREDICTION_LOG_SCHEMA columns:
    timestamp_utc, asset, horizon, forecast_var, model_version, alias.
  Service stats: total row count, max(timestamp_utc) as last-forecast time,
    and the latest forecast_var per asset (groupby asset, last by timestamp_utc).

API /health (from src/volforecast/serving/app.py):
  GET {API_BASE_URL}/health -> 200 JSON
    {"status":"ok","model_name":"volforecast-lgbm","model_version":"<N>","alias":"champion"}
  Returns 503 if the model failed to load. Measure round-trip latency around the call.

Asset universe (from src/volforecast/config.py):
  load_assets() -> list of {symbol, asset_class, exchange};
  symbol_slug("BTC/USDT") -> "BTC-USD". The asset selector should offer the
  slugs that actually appear in the FVR parquet; fall back to symbol_slug over
  load_assets() when the parquet is empty.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host browser → dashboard (8501) | A human on the dev machine views the dashboard over loopback only |
| dashboard container → MLflow registry (5000) | Read-only metadata query over the compose network |
| dashboard container → API /health (8000) | Read-only liveness probe over the compose network |
| dashboard container → data/ bind mount | Read of monitoring + prediction parquet/JSON artifacts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | dashboard port exposure | mitigate | Publish only `127.0.0.1:8501:8501` (loopback) — never LAN-exposed, matching the api/mlflow/prefect posture (WR-05). No secrets rendered: champion panel shows version/run-id/params/metrics, never credentials or artifact bytes. |
| T-05-02 | Tampering | dashboard writes to registry/data | mitigate | Dashboard is strictly read-only: data_access.py and app.py contain NO `set_registered_model_alias`, NO `.to_parquet`, NO write-mode file open (grep-verified in acceptance criteria). Drift is REPORT-ONLY and the UI states it never implies promotion. |
| T-05-03 | Denial of Service | malformed/missing input files crash the app | mitigate | Every loader swallows missing-file / unreachable-service / malformed-parquet errors and returns a neutral empty value; the container stays up on `docker compose up` before any pipeline run (empty-state path is the default first-run path). |
| T-05-04 | Elevation of Privilege | compromised dashboard process | mitigate | Container runs as non-root `appuser` (uid 1000), mirroring the api Dockerfile. The `../data:/data` mount is the only writable surface by design but the code never writes to it. |
| T-05-SC | Tampering | npm/pip install (streamlit) | mitigate | `streamlit==1.58.0` is a CLAUDE.md-locked, mainstream PyPI package already vetted in the stack research (Confidence HIGH); no new untrusted package introduced. See note below — no blocking checkpoint required. |
</threat_model>
