Compose file: infra/docker-compose.yml. Bring up with:
  docker compose -f infra/docker-compose.yml up -d
Services + host ports (all bound to 127.0.0.1):
  postgres        5433 (host) / 5432 (internal)
  mlflow-server   5000   (MLflow tracking + registry UI)
  prefect-server  4200   (Prefect UI)
  prefect-worker  (no published port)
  api             8000   (FastAPI: /health, /forecast, /forecast/{symbol})
  dashboard       8501   (Streamlit observability dashboard — added in Plan 05-01)
Credentials: cp infra/.env.example infra/.env then set POSTGRES_PASSWORD (the stack
  refuses to start without it).

First-run sequence to populate state so the dashboard shows real data
(the dashboard itself comes up empty-state before any of this):
  1. uv sync --dev
  2. uv run volforecast ingest --start 2022-01-01        (CLI ingest subcommand — exists)
  3. uv run python scripts/generate_features.py          (build feature parquet)
  4. uv run python scripts/train_lgbm.py                 (train + MLflow track + register @champion)
  5. uv run python scripts/eval_lgbm.py                  (regenerate reports/ml_vs_baselines.*)
  6. exercise the API: GET http://localhost:8000/forecast  (writes prediction-log rows)
  7. uv run python scripts/run_labeller.py               (build data/monitoring/forecast_vs_realized.parquet)
  8. uv run python scripts/create_reference_snapshot.py  (frozen drift reference)
  9. uv run python scripts/create_deployment.py          (register the Prefect daily deployment)
 10. run the daily flow: pipelines/daily_pipeline.py:daily_flow (scheduled, or
     PREFECT_API_URL=http://localhost:4200/api uv run prefect deployment run 'volforecast-daily/volforecast-daily')
Verify the dashboard at http://localhost:8501.
NOTE: do NOT invent CLI subcommands (e.g. `volforecast train`) — only `volforecast ingest`
exists; training/eval/labelling/deployment are the scripts listed above.

Lifecycle for the Mermaid diagram (nodes + flow direction):
  config/assets.yaml -> ingest (ccxt crypto / yfinance equity) -> validate_asset (Pandera +
  calendar gate; failures -> data/quarantine) -> data/processed (DVC-tracked) ->
  build_features (single codepath) -> walk-forward train/eval (LightGBM vs EWMA/GARCH/HAR on
  identical folds) -> MLflow registry (volforecast-lgbm @champion/@challenger) -> FastAPI
  serving (loads @champion) -> prediction log (data/predictions/predictions.parquet) ->
  labeller (forecast_vs_realized.parquet) -> Evidently drift (REPORT-ONLY) + rolling-QLIKE
  performance monitor (champion vs GARCH; the authoritative retrain trigger + alert) ->
  promotion gate (QLIKE-gated, default no-promote, rollback = alias flip) -> Prefect daily
  flow orchestrates ingest..promotion-gate on schedule + on performance-drift trigger.
  Streamlit dashboard reads forecast_vs_realized + drift reports + MLflow registry + /health.
  Drift is REPORT-ONLY and NEVER feeds the promotion gate (locked anti-pattern).
